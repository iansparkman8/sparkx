# House

One launch. Ara and Aperture on the same phone. The Android overlay stays in SparkXFairyOS.

Open `index.html` in Chrome. The corner must say `live`. Chat preview does not run the buttons.

- Door — what this is, and what it is not
- Ara — local replies, lessons kept as text, she can say no
- Aperture — what became real, what you left unreal
- Record — both, exportable, still on the device

No account. No checkout. Export is the archive.

Older doors stay up: [ara-born](https://github.com/iansparkman8/ara-born), [aperture](https://github.com/iansparkman8/aperture), [SparkXFairyOS](https://github.com/iansparkman8/SparkXFairyOS).

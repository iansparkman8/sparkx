# Aperture

A private room. It keeps what you made real, and what you left unreal on purpose. It does not advise you.

A life is not the field of what was possible. It is the narrow set that survived your refusal. The second field exists so a refusal has the same dignity as an achievement.

The room has one intelligence: your earlier self. When a new entry resembles an old one, it returns that older line. It will not invent a wiser voice than yours.

## Open it

The working room is [index.html](index.html). On GitHub that file is also the site root.

Phone, so the buttons actually run:

1. Open the site or the raw `index.html` in Chrome. The chat preview will not run the script.
2. The corner must say `live`. If it says `starting`, you are not in a real browser.
3. Menu, Add to Home screen. iPhone: Share, Add to Home Screen.
4. Write one line. Tap **Keep this**. Tap **Record** to see it.

Nothing leaves the device until you export. Export is the whole archive, a JSON file you can read without this app.

## What the controls do

- **Room** — two fields. What became real. What you left unreal on purpose. Keep stores both. Speak fills the first field if the browser allows the microphone.
- **Chapters** — a named stretch of a life. Entries belong to the open chapter. Closing a chapter does not delete it.
- **Record** — what you kept, newest first, with the older line it resembled.
- **Pattern** — entries, refusals, and words that keep returning. No score. No streak.
- **Creed** — why the room exists. Import and erase live here. Export is in the header.

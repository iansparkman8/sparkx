# SparkX Monorepo

Single home for Ara / Spark Baby / FairyOS and related projects.

Everything that was previously scattered across multiple repos now lives here so you can find and work on what you need without hunting.

## Folders

| Folder | Origin repo | Status |
|--------|-------------|--------|
| `fairyos/` | [SparkXFairyOS](https://github.com/iansparkman8/SparkXFairyOS) | Full Android tree imported (incl. assets) |
| `ara-born/` | [ara-born](https://github.com/iansparkman8/ara-born) | Full imported (door, baby, body, assets, scripts) |
| `ara/` | [ara](https://github.com/iansparkman8/ara) | README |

| `experiments/` | various archived | Optional |

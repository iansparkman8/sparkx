# Omni-Realm Nexus

Phase 1 — 6-Continent Shard Manifest.

Browser-based, local-first RPG. No account, no server. Progress lives in localStorage.

## Play

Once GitHub Pages is enabled:

**https://iansparkman8.github.io/omni-realm-nexus/**

## Enable Pages (one click)

1. Repo → Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / `/ (root)`
4. Save

Site goes live in 1–2 minutes.

## What it is

Six continents. Collect Primary Shards. Unlock the later ones by securing earlier shards. Energy regenerates slowly. Everything stays on your device.

`.nojekyll` is present so Pages serves the static files cleanly.

What she is

Living holographic

Canvas-drawn fairy with breathing, wing flutter, mood-reactive aura, speaking mouth, and orbiting particles. She feels present.

Floating overlay

Draggable fairy bubble that lives above any app. Long-press for free roam. Notification controls to show, hide, or stop.

Teach & Grow

Local memory on the device. Lessons, notes, and behaviors stay with you. Export is the only way anything leaves.

Voice, on-device

Speech recognition and text-to-speech run locally. Optional cloud AI keys are stored in Android Keystore.

How to install

  1. Tap Download APK above. On the GitHub Releases page, download the latest app-release.apk (or the debug APK if a release build is not yet attached).
  2. On your Android phone, open the downloaded file. If prompted, allow installation from this source (Settings → Apps → Special access → Install unknown apps).
  3. Confirm the install. Package name is com.sparkx.fairyos.
  4. Open SparkX Master. Grant Overlay, Microphone, and Notifications when asked.
  5. Optional: set it as your home app (Settings → Apps → Default apps → Home app) so she is the face of your phone.
  6. Say hello. She is there.

Safe Companion is the default. Owner Mode is explicit, visible, and every powerful action requires your confirmation. No screen scraping. No hidden data collection.
